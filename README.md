# Интернет-магазин

## Описание проекта

Проект реализует ядро интернет-магазина с использованием ООП-подхода.

## Классы

### Product
Класс для представления товара.

**Атрибуты:**
- `name` — название товара
- `description` — описание товара
- `__price` — приватная цена (float, может быть с копейками)
- `quantity` — количество в наличии (int)

**Методы:**
- `new_product(product_data)` — создаёт продукт из словаря
- `price` (геттер/сеттер) — получение и установка цены с проверкой
- `price` (сеттер) — подтверждение понижения цены

### Category
Класс для представления категории товаров.

**Атрибуты:**
- `name` — название категории
- `description` — описание категории
- `__products` — приватный список товаров

**Атрибуты класса:**
- `category_count` — количество созданных категорий
- `product_count` — общее количество товаров во всех категориях

**Методы:**
- `add_product(product)` — добавляет продукт в категорию
- `products` (геттер) — возвращает строку со всеми товарами

## Структура проекта

```
├── main.py              # Точка входа
├── pyproject.toml       # Конфигурация проекта
├── README.md            # Документация
├── data/                # Данные

│   └── products.py      # Классы Product и Category
└── tests/               # Тесты
    ├── conftest.py      # Фикстуры pytest
    └── test_products.py # Тесты для продуктов
```

## Тестирование

Запуск тестов:
```
pytest
```

Отчёт о покрытии:
```
pytest --cov=src --cov-report=html
```

Отчёт доступен в папке `htmlcov/index.html`.
