## Классы

### BaseProduct

Абстрактный базовый класс для всех продуктов.

Определяет контракт для всех продуктов — абстрактный метод `price` (геттер/сеттер).

#### Абстрактные методы

| Метод | Описание |
| --- | --- |
| `price` (геттер/сеттер) | Абстрактные методы для получения и установки цены |

### PrintInfoMixin

Класс-миксин для печати информации о созданном объекте.

Добавлен в цепочку наследования класса `Product`.

#### Поведение

При создании любого объекта, наследующего `PrintInfoMixin`, в консоль выводится информация о классе и параметрах:

```
ClassName('name', 'description', price, quantity)
```

#### Примеры вывода

- `Product('Товар', 'Описание', 100.0, 5)`
- `Smartphone('iPhone 15', 'Флагман', 99990.0, 10)`
- `LawnGrass('Газон', 'Смесь трав', 500.0, 20)`

### Product

Класс для представления товара.

Наследуется от `BaseProduct` (абстрактный базовый класс) и `PrintInfoMixin` (для печати информации при создании).

**Абстрактные методы:** наследует абстрактные `price` (геттер/сеттер) от `BaseProduct`.

#### Атрибуты

| Атрибут | Тип | Описание |
| --- | --- | --- |
| `name` | `str` | Название товара |
| `description` | `str` | Описание товара |
| `__price` | `float` | Приватная цена (может быть с копейками) |
| `quantity` | `int` | Количество в наличии |

#### Методы

| Метод | Описание |
| --- | --- |
| `new_product(product_data)` | Создаёт продукт из словаря |
| `price` (геттер/сеттер) | Получение и установка цены с проверкой на положительное значение и подтверждением понижения |
| `__str__()` | Строковое представление: "Название, X руб. Остаток: X шт." |
| `__add__(other)` | Сумма стоимости двух товаров **одинакового класса**: price1 × quantity1 + price2 × quantity2 |

**Ограничение сложения:** Можно складывать только объекты одного класса (например, Product + Product, Smartphone + Smartphone). При попытке сложить объекты разных классов выбрасывается `TypeError`.

### Category

Класс для представления категории товаров.

#### Атрибуты

| Атрибут | Тип | Описание |
| --- | --- | --- |
| `name` | `str` | Название категории |
| `description` | `str` | Описание категории |
| `__products` | `list[Product]` | Приватный список товаров |

#### Атрибуты класса

| Атрибут | Тип | Описание |
| --- | --- | --- |
| `category_count` | `int` | Количество созданных категорий |
| `product_count` | `int` | Общее количество товаров во всех категориях |

#### Методы

| Метод | Описание |
| --- | --- |
| `add_product(product)` | Добавляет продукт в категорию (принимает только Product или его наследников) |
| `products` (геттер) | Возвращает строку со всеми товарами |
| `products_list` (геттер) | Возвращает список продуктов |
| `__str__()` | Строковое представление: "Название, количество продуктов: X шт." |

**Ограничение добавления:** Метод `add_product()` принимает только объекты типа `Product` или его наследников (`Smartphone`, `LawnGrass`). При попытке добавить объект другого типа выбрасывается `TypeError`.
