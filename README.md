## Классы

### Product

Класс для представления товара.

#### Атрибуты

| Атрибут | Тип | Описание |
| --- | --- | --- |
| `name` | `str` | Название товара |
| `description` | `str` | Описание товара |
| `__price` | `float` | Приватная цена (может быть с копейками) |
| `quantity` | `int` | Количество в наличии |

#### Методы

| Метод | Описание |
| --- | --- |
| `new_product(product_data)` | Создаёт продукт из словаря |
| `price` (геттер/сеттер) | Получение и установка цены с проверкой на положительное значение и подтверждением понижения |
| `__str__()` | Строковое представление: "Название, X руб. Остаток: X шт." |
| `__add__(other)` | Сумма стоимости двух товаров: price1 × quantity1 + price2 × quantity2 |

---

### Category

Класс для представления категории товаров.

#### Атрибуты

| Атрибут | Тип | Описание |
| --- | --- | --- |
| `name` | `str` | Название категории |
| `description` | `str` | Описание категории |
| `__products` | `list[Product]` | Приватный список товаров |

#### Атрибуты класса

| Атрибут | Тип | Описание |
| --- | --- | --- |
| `category_count` | `int` | Количество созданных категорий |
| `product_count` | `int` | Общее количество товаров во всех категориях |

#### Методы

| Метод | Описание |
| --- | --- |
| `add_product(product)` | Добавляет продукт в категорию |
| `products` (геттер) | Возвращает строку со всеми товарами |
| `products_list` (геттер) | Возвращает список продуктов |
| `__str__()` | Строковое представление: "Название, количество продуктов: X шт." |

## Тестирование

Запуск тестов:

```bash

```

Отчёт о покрытии:

```bash
pytest --cov=src --cov-report=html
```
